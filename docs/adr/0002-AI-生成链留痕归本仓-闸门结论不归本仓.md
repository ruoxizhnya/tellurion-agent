# 0002 · AI 生成链的留痕归本仓，promote 闸门的结论不归本仓

- **状态**：已裁决（2026-10-25，QT-32-A / core QT-32 ⑥「生成质量与实验编排属 agent 仓」）
- **场景**：一次 copilot 生成的产物只活在内存 `jobs sync.Map` 和一个 `defer os.RemoveAll` 的临时目录里，`ai.*` 没有任何一列装得下 prompt / 源码 / 指纹；链的最后一环更糟——`go build` 出来的不是 plugin，`plugin.Open` 必然失败后回落成硬编码字面量 `"generated-strategy"`，再拿这个名字去 core 跑回测，而 core 从未注册过它（`grep -rn 'generated-strategy' tellurion:pkg tellurion:cmd` = 0 命中）。于是「AI 生成 → 回测结果」这条产品主链路，断点既看不见、也查不到。
- **决策**：
  1. 本仓新增 `ai.generation_chain`（**一行 = 一次编译尝试**，主键 `(job_id, attempt)`），存人给的意图（prompt + 回测区间）、这一 attempt 的源码、该源码的 sha256 指纹、编译结论、以及链被拦下的原因。
  2. **留痕是生成的前置**：没注入留痕落点（或写不进去）就不开始，连 LLM 都不调——一条记不下来的生成等价于一次无法复查的生成。
  3. **闸门结论不在本仓**：不存 `promoted`、不存资产服务的 `status`。本仓只按「有没有可核验的产物坐标」拦——今天没有，所以 AI 产物一律不进回测，`blocked_reason=promote_gate` 留下为什么停。
  4. 指纹列叫 `source_sha256`，不叫 `version_hash` / `artifact_hash`：前者需要资产服务签发的 `strategy_id` 才编得出来（`tellurion-contracts:engine/provenance.go:65` 六项输入），后者只覆盖编译产物字节（同文件 `:39`）。
  5. 删除 `loadPluginSymbol`（`plugin.Open`）与硬编码策略名，`Generate` 不再接收 runner 参数。
  6. **两条轴不共用一列**：链上「编不过」写 `build_error`、「编过了但不许跑」写 `blocked_reason`，终态出口因此分成 `stop` 与 `stopAtGate` 两个函数。给人看的解释只在 job 的 `build_error`（wire 字段）里，链上说话的是枚举。合并成一列的代价是读库的人分不出这两种失败，而那正是生成质量要看的差别；钉子是 `TestQT32A_PromoteGateBlocksEvenAfterSuccessfulBuild` 断言闸门终态的链行 `build_error` 为空（破坏验证 G 条取证：把闸门改走 `stop` 当场红）。
- **理由**：被否掉的四个选项——
  - **塞进 `ai.experiments.params` JSONB**：那一列的写者是 pipeline（`{"intent": …}`），再叠一份链进去就是两种语义挤一个字段；而且 `ai.experiments` 是 QT-17 从 core 逐列搬来的表，drift 护栏要求它与 core 列集一致，加不了列。
  - **在本仓复制一份 `strategy_artifacts.status`**：闸门就有两处真相，且本仓那份一定会漂。资产服务的 `internal/httpapi/api.go` 自己写着「promote 是人的闸门」。
  - **本仓自算 `version_hash`**：拿一个自己编的 `strategy_id` 算出来的 hash，资产服务不认，等于造一个看着像坐标的字符串——比没有更坏。
  - **保留旧路径、只是标个状态**：那等于把「跑的就是这一份源码」这个宣称继续留着，而它从来不成立。
- **代价 / 后果**：
  - `JobResult.StrategyName / BacktestResult / BacktestErr` 与 `/api/copilot/stats` 的 `backtest_valid`、`acceptance_rate` 今天**结构上恒为空/0**。字段保留是因为它们是对外的 wire 契约（`tellurion-ui:web/src/types/api.ts`、`api/copilot.ts` 的终态白名单），删字段是跨仓 breaking；填上它们是接资产服务那一单的动作。机械检查：`TestQT32A_PromoteGateBlocksEvenAfterSuccessfulBuild` 钉住 `backtested == 0`。
  - `pkg/copilot` 不再有回测通道，`contracts.BacktestRunner` 的别名腿只剩 pipeline 一侧（`pkg/ai/pipeline/backtest_runner_alias_test.go`）——护栏覆盖面小了一边，不是被放宽。
  - 「假路径不许复活」靠源码级禁 token 守卫（`plugin.Open` / `"generated-strategy"` / `RunBacktest(`），改名或拆串能绕过它；它是防复活的哨兵，不是安全边界。
  - 留痕表把 prompt 与源码全量入库、不压缩：一次生成 N 次尝试就是 N 行。换掉的是「事后能否复查」，代价是行宽。
  - 本仓自持表需要 `agentOwnedTables` 显式豁免（QT-17 的 drift 护栏原本假设每张 `ai.*` 表都有 core 对应物）。豁免名单本身由 `TestSchema_AgentOwnedTablesAreDeclared` 四条腿钉住：没登记、DDL 里没有、与 core 搬迁同时出现、理由为空——任一种都红。
- **替代关系**：不替代本仓既有条目。它把 core `ADR-024`（LLM 生成的 Go 只是可审阅 artifact，**不加载、不执行**）与本仓 `docs/api-schema.md` §5（「不做策略执行沙箱」）第一次落成代码事实：旧实现里那个 `plugin.Open` 与这两句是冲突的。
